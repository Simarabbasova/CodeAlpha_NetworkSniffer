# CodeAlpha_NetworkSniffer

Basic network sniffer built with Python and Scapy (CodeAlpha Cyber Security Internship, Task 1).

## Features
- Captures live network packets
- Shows source/destination IP addresses
- Identifies protocols (TCP, UDP, ICMP)
- Displays ports, TCP flags and payload

## Requirements
- Python 3
- Scapy (`pip install scapy`)
- Npcap (Windows)

## Usage
Run CMD as Administrator:
python sniffer.py

Press Ctrl+C to stop.

## Note
For educational purposes only. Use only on networks you own or have permission to monitor.
